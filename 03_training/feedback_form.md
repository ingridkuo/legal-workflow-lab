# Sample product feedback form

Use this template with approved tools and synthetic or authorized public evidence.

- Feedback ID:
- Date and reporter role:
- Product or workflow:
- Task the user was trying to finish:
- Expected result:
- Observed result:
- Minimal reproduction steps:
- Safe quote and source locator:
- Evidence source and data-handling check:
- Impact and affected users:
- Severity and reason:
- Owner role:
- Next action and update date:
- Authorized reviewer decision, where needed:
- Verification task and evidence after the change:
- User confirmation and remaining open items:
- Closure owner and date:

## Sample severity guide

| Severity | Working definition |
| --- | --- |
| S1 | Source integrity, unsafe output, or confidentiality concern: pause the affected task and name the reviewer. |
| S2 | Core task blocked. |
| S3 | Workflow degraded. |
| S4 | Enhancement request. |

These are support priorities. NDA risk levels determine contract escalation separately.

## Before closing

Repeat the original useful task, retain the evidence, and record the user's confirmation or remaining limitation.
