    The result, with its scope intact
    Ingrid Kao reviewed all 25 reference issue labels across 20 synthetic NDAs; none changed. The held-out set contains 15 documents and 16 reference issues. Its 16 findings match that key, with exact source quotes and Section locators.
    v1’s extra PURPOSE finding is source-supported overlap. v2 consolidates it under residuals and model training. That improves counting consistency; it does not prove greater legal accuracy.
    These deliberately constructed documents share patterns and review context. The results describe this set, not performance on new contracts or repeated runs. A percentage or population confidence interval would add precision the experiment does not support.
    Decision: supervised pilot
    Use approved inputs and a reviewed policy. Before production, test representative agreements, reviewer agreement, source access, approval enforcement and user task completion. A model’s human-review flag is an output field, not a working approval system.
