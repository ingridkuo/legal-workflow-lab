# Changelog

What each release of the Lab adds. Dates are release dates.

## 1.0.0 (first release, not yet dated)

- License terms: code and demo data under the MIT License, written material under CC BY 4.0, and a list of what stays reserved.
- `CITATION.cff`, so a release can be cited.
- The supplier compliance series opens: its page, the schedule for 2027, and the tools already in the Lab that a supplier can use.
- Two public forms under Issues: one for saying how a tool was used, one for corrections.
- Release archives leave out the reserved files.

Everything before this release is in the commit history.
