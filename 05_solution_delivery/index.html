What is checked

Executable controls, with a defined boundary.

Compare the destination with an independent source

The check does not validate a transformation against itself. It compares the XML export with the separately saved JSON destination, using a source-to-destination crosswalk.

Source IDs, revisions, required owners, dates and access metadata remain visible when a record is held.

Preserve meaning during import

Amounts use exact decimals. A missing amount stays null; a known zero stays zero. DTD/entity input is rejected, and destination identifiers are checked for case-insensitive collisions.

Metadata matching does not establish that real system permissions are enforced.
